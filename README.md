# Speech Enhancement Demo

This is a temporary GitHub Pages test site.

## Files

- `index.html`: web page
- `audio/`: WAV files

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `speech-enhancement-demo`.
2. Upload `index.html` and the entire `audio` folder to the repository root.
3. Open the repository's **Settings**.
4. Open **Pages** in the left sidebar.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.
7. Wait about 1–3 minutes.
8. GitHub will show the public site URL on the Pages settings page.

Typical URL:
`https://YOUR-USERNAME.github.io/speech-enhancement-demo/`
